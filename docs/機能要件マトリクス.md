#機能要件一覧

| ID | 機能名 | 機能詳細 | 関連データ | 関連ユーザー | 備考 |
|---|---|---|---|---|---|
| 1 | ログイン | 登録済みユーザーがログインする | ユーザーID<br>パスワード | 一般社員<br>管理者 | |
| 2 | ログアウト | システムからログアウトする | ユーザーID | 一般社員<br>管理者 | |
| 3 | ユーザー登録 | ユーザー情報を登録する | ユーザーID<br>氏名<br>メール<br>パスワード<br>権限 | 管理者 | |
| 4 | カレンダー表示 | 月単位で勤怠情報を表示する | 日付 | 一般社員<br>管理者 | |
| 5 | 出勤打刻 | 勤務開始時刻を記録する | 勤務日<br>開始時刻 | 一般社員 | |
| 6 | 退勤打刻 | 勤務終了時刻を記録する | 勤務日<br>終了時刻 | 一般社員 | |
| 7 | 勤怠確認 | 勤怠情報を確認する | 勤務日<br>勤怠情報 | 一般社員<br>管理者 | |
| 8 | 残業計算 | 実働8時間超過分を算出する | 開始時刻<br>終了時刻 | 一般社員<br>管理者 | |
| 9 | 天気表示 | 天気・気温を表示する | 天候<br>最高気温<br>最低気温 | 一般社員<br>管理者 | 外部API |
| 10 | 簡易メモ管理 | 日付ごとにメモを管理する | 勤務日<br>メモ内容 | 一般社員 | |
| 11 | CSV出力 | 勤怠情報をCSV出力する | 勤怠情報 | 管理者 | CSV |
